# Agents and distribution surfaces

The [vision](vision.md) includes agent handoff as a distribution and resolution loop. One Flag should provide portable, evidence-backed context for a coding agent, then independent verification should determine recovery.

The website's URL-to-Site experience remains primary acquisition. Existing CLI/MCP infrastructure is a reusable or parked transport, not a mandatory install-first journey. Current customer commands remain documented where they actually work; do not advertise new Site APIs or automation before implementation.

No unsolicited prompts, auto-deploys or changes in the user's tools. Export or send only after the user's action/authorization. Repository publication and open-source licensing decisions are separate from adopting the vision and require explicit scope.
