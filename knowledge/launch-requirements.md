# Next-version launch requirements

[ROADMAP.md](../ROADMAP.md) owns phase exit criteria. [The PRD](../docs/product-prd.md) owns acceptance scenarios. [QUALITY.md](../QUALITY.md) owns verification and release evidence.

Launch requires a real URL-to-Site journey, scoped health and coverage, useful Flags, independent verification, durable Keep watching, sustainable free/paid responsibility, private ownership, and truthful public communication. Only working context adapters belong in released claims.

Prove legacy account/billing/history migration and old public link behavior before removing compatibility surfaces. Passing old report tests alone is insufficient; new Site behavior must be exercised. Do not label roadmap preparation as a product launch.
