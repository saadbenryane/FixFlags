# Knowledge Base

**Canonical company knowledge for AI agents.** Load relevant files into context before coding product, business, or growth work.

## Files

| File | Contents | Load when... |
|------|----------|-------------|
| `foundations.md` | Thesis, brand, 25 principles, research validation | Starting any work, making product decisions |
| `market.md` | Market context, competitors, segments, risks, distribution | Building growth/marketing features, competitive analysis |
| `product.md` | Architecture, Product Contract, flags, truth system, security, auth testing, benchmark | Designing product surfaces, flag quality, testing architecture |
| `strategy.md` | Pricing, revenue model, segments, unit economics | Modifying pricing, billing, or revenue features |
| `execution.md` | 6-month milestones, what to build/defer, weekly dashboard | Planning sprints, prioritizing work, tracking progress |

## Reading order

1. `foundations.md` — always first. Establishes the thesis and principles everything else builds on.
2. One of `market.md`, `product.md`, `strategy.md`, `execution.md` depending on the task.
3. Cross-reference as needed (files link to each other for related topics).

## Principles

- Each concept lives in ONE file. No duplication across files.
- These are living documents. Update them as strategy evolves.
- When sharing new knowledge, update the relevant file in place.
