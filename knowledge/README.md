# Knowledge Base

**Canonical company knowledge for AI agents.** Load relevant files before product, business, or growth work.

## Files

| File | Contents | Load when... |
|------|----------|-------------|
| `vision.md` | Full product vision (one narrative home) | Any strategic or product decision |
| `foundations.md` | Thesis, short principles, research validation | Starting work; principle conflicts |
| `product-intelligence.md` | Customer PI model, Contract, portability | PI persistence, Contract, dismissals |
| `integrity-engine.md` | Engine, 5 dimensions ↔ 3 rubrics, truth | Checks, scoring, pipeline design |
| `finish-plan.md` | Finish Plan artifact definition | Report priorities, ranking, MCP plan |
| `privacy.md` | Privacy / trust principles | Data handling, learning, export |
| `open-source.md` | What to open vs keep closed | CLI, protocol, OSS questions |
| `market.md` | Market, competitors, segments, distribution | Growth, marketing, competitive |
| `product.md` | Pointer hub to product canon | Quick routing |
| `strategy.md` | Pricing direction + live tier table | Billing, packaging |
| `execution.md` | FixFlags own Finish Plan / build order | Planning, prioritization |

## Reading order

1. `vision.md` — north star (or `foundations.md` for a shorter thesis).
2. `PRODUCT.md` (repo root) — what ships today. Never confuse with vision.
3. Task-specific file from the table above.
4. `execution.md` + `ROADMAP.md` for sequencing.

## Principles

- Each concept lives in **one** file. Link; do not duplicate narrative.
- Living documents: update in place when knowledge is verified.
- Shipped facts belong in `PRODUCT.md` / code; strategy belongs in `knowledge/`.
