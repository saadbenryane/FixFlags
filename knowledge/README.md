# Knowledge Base

**Canonical company knowledge for AI agents.** Load relevant files into context before coding product, business, or growth work.

## Files

| File | Contents |
|------|----------|
| `revenue-model.md` | Pricing, segments, revenue targets, $1M ARR path, unit economics |
| `execution-plan.md` | 6-month milestones, what to build/defer, weekly dashboard, probability assessment |
| `market-and-distribution.md` | Market context, customer profiles, willingness to pay, channels, partnerships |
| `product-architecture.md` | Product Contract, intent layer, two product surfaces, authenticated testing, change awareness, security discipline, benchmark |

## How to use

- Before coding a new feature, check `execution-plan.md` for build/defer decisions.
- Before modifying pricing or billing, check `revenue-model.md` for segment targets and constraints.
- Before building growth or marketing features, check `market-and-distribution.md` for channel strategy.
- Before designing product surfaces, flag quality, or testing architecture, check `product-architecture.md`.
- These files are living documents. Update them as strategy evolves.
