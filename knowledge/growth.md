# Growth and activation

Follow the distribution loops in the [vision](vision.md) and delivery order in [ROADMAP.md](../ROADMAP.md).

Measure the meaningful journey: URL submitted, useful Site result, inferred Outcome confirmed/corrected, meaningful Flag understood, fix handed off, independent recovery verified, Site saved, ongoing care established, useful alert acted upon, Site retained. Reuse the existing event infrastructure but reconcile the event catalog when each new surface ships.

Acquisition is useful analysis. Activation is choosing Keep watching and receiving actual care. Retention includes quiet healthy coverage, not only Flag or login volume. Shareable evidence, agency/client collaboration, agent handoffs and Shopify distribution should lead into the same Site model.

Do not optimize for more Flags, more alerts, superficial scores or integrations connected without value. Marketing claims require measured evidence. Avoid sending growth messages without the user's authorization.
