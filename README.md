# QualityOS

Post-build QA for AI-shipped apps. Audit any public URL across 7 quality areas, get evidence-backed findings with copy-ready fix prompts, and re-check after your agent applies fixes.

## Development

```bash
npm install
npm run dev
```

See [MCP Integration docs](https://qualityos.com/docs/mcp) for connecting to Cursor, Claude Code, or Windsurf.

Voice and copy guidelines: [`docs/voice-and-copy.md`](docs/voice-and-copy.md)
