# Handoffs

Handoffs describe incomplete work that another person or agent must continue, review, integrate, or unblock. They are not default context and do not define product direction. See the [coordination contract](../README.md).

Before resuming a handoff, confirm that its lease and scope are current, inspect the actual worktree state, and reconcile its assumptions with the [September 21 vision](../../knowledge/vision.md) and [canonical source map](../../CANONICAL-SOURCES.md). Preserve valid implementation evidence without reviving obsolete report, Shopify-only, or separate-product direction.

Do not create a handoff for completed routine work. Do not include secrets, customer data, raw prompts, source dumps, or full tool logs.
