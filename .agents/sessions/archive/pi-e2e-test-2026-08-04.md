## Critical Findings (Blockers for Launch)

### 1. Server-Side Rendering Error on Report Page — **HIGH**
- **Reproduction**: Visit `/report/cmsdv87jf0001guwwsatpuoch` (linear.app audit)
- **Error**: "Attempted to call buildPlaybackSteps() from the server but buildPlaybackSteps is on the client"
- **Impact**: Report falls back to client-side rendering, progressive UI may not render correctly for anonymous users
- **Suggested fix**: Move `buildPlaybackSteps()` call to a client component or wrap in `useEffect`/dynamic import with `ssr: false`

### 2. AI Review Fails Due to Invalid API Key — **HIGH**
- **Reproduction**: Any audit submission
- **Error**: "401 Incorrect API key provided: sk-432Ms..."
- **Impact**: Anonymous users get PARTIAL reports (deterministic only), no AI triage, no AI-generated fix prompts beyond the one hardcoded for the top flag
- **Suggested fix**: Rotate `OPEN_CODE_API_KEY` in `.env.local` to a valid OpenAI key

### 3. Bolt.new Audit Fails (Desktop Screenshot Capture) — **MEDIUM**
- **Reproduction**: Submit `https://bolt.new` for audit
- **Error**: "Desktop screenshot capture failed for [url]"
- **Impact**: Known AI-builder reference site cannot be audited
- **Suggested fix**: Investigate Playwright navigation — may need auth handling or wait strategy adjustment

### 4. Vercel.com Flow Scan Timeout — **MEDIUM**
- **Reproduction**: vercel.com audit shows "Flow scan timeout"
- **Impact**: Funnel/CTA flow incomplete for this reference site
- **Suggested fix**: Increase flow scan timeout or improve CTA detection for Vercel's navigation

## High-Impact Improvements (Non-Blocking)

### 1. Anonymous Finish Plan UI Polish — **HIGH IMPACT, MEDIUM EFFORT**
- **Finding**: API returns correct data (1 demonstrated prompt, rest gated) but browser UI not verified
- **Impact**: First-value moment for all users
- **Effort**: Verify progressive report renders correctly post-SSR fix
- **Suggested fix**: Test with real browser after SSR fix; ensure "How FixFlags is checking" stays collapsed

### 2. Fix Prompt Generation for Deterministic Flags — **HIGH IMPACT, HIGH EFFORT**
- **Finding**: Only 1/16 (linear.app) and 1/9 (vercel.com) flags have fix prompts in anonymous view
- **Impact**: Users see generic "why it matters" but no actionable fix for most flags
- **Effort**: Requires AI triage to generate prompts; or enhance deterministic checks with template prompts
- **Suggested fix**: Fix API key to enable AI triage; or add deterministic prompt templates for common checks

### 3. Mobile Viewport Evidence Anchors — **MEDIUM IMPACT, LOW EFFORT**
- **Finding**: Evidence anchors use normalized coordinates (0-1) but mobile viewport comparison toggle not tested
- **Impact**: Mobile-specific flags (cta-below-fold-mobile, mobile-lcp-critical) need clear visual evidence
- **Effort**: Verify screenshot overlay/gif URLs render correctly in browser
- **Suggested fix**: Test `flagVisualEvidence` URLs in browser at 375px

### 4. Duplicate Flag Consolidation Across Pages — **MEDIUM IMPACT, MEDIUM EFFORT**
- **Finding**: linear.app shows same `buttons-no-text`, `links-no-text`, `color-contrast-poor` across 4 pages but consolidated to 1 flag each
- **Impact**: Good consolidation working, but verify `occurrenceCount` and `pageUrls` arrays are accurate
- **Effort**: Audit fingerprint logic
- **Suggested fix**: Verify `fingerprint` field correctly deduplicates cross-page issues

### 5. Score Ceiling Enforcement Visibility — **LOW IMPACT, LOW EFFORT**
- **Finding**: Score 57/70 with CRITICAL flags respects ceiling (≤74), but UI doesn't explain why
- **Impact**: Users may not understand score cap
- **Effort**: Add tooltip "Score capped due to Critical Flags" in progress band
- **Suggested fix**: Enhance `#report-status` component
