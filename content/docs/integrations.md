## Available integrations

[GitHub account authorization](/docs/integrations/github) is available. Connecting saves encrypted authorization; it does not inspect code or open pull requests.

## Planned integrations

These connections become available after testing and validation. Website checks, Flags, fix instructions, rechecks, and monitoring work without them.

| Connection | What it will add |
| --- | --- |
| [Shopify](/docs/integrations/shopify) | Store and selected product-path context. |
| [Google Analytics](/docs/integrations/google-analytics) | Traffic context beside checked pages. |
| [Google Search Console](/docs/integrations/google-search-console) | Search demand and recorded indexing context. |

See the [integrations overview](/integrations) for the full lineup.

## Connect to a Site

Open your Site’s **Settings** to manage GitHub authorization. You can [check your website](/docs/getting-started), save the Site, and use its independent checks now.

If you previously saved a connection, its dated records remain available. Open the Site’s **Settings** to disconnect it. Uninstall any existing Shopify app separately in Shopify admin to revoke its external access.

## Context and proof

Traffic and search context stays separate from independently verified recovery. Provider reports cannot establish that signup, checkout, or a fix works.

After a website fix, [check the Flag again](/docs/site-care#verify) for independent evidence.
