# Branding Reference Assets

This directory contains branding reference images used by the agentic workflow
for design inspiration and visual consistency checks. These are not public
assets and are not served by the application.

**Usage:** Design agents reference these images when creating or reviewing
marketing pages, ensuring visual decisions align with the established brand
direction.

**Do not** add these to `public/`, reference them from components, or commit
new assets without reviewing the brand guidelines in `docs/brand-positioning.md`.

**Mood reference only, partially stale.** These boards predate the current
system: they show a Canela/Inter type stack and five audit categories, both
superseded (Fraunces/Satoshi/IBM Plex Mono; three rubrics: Message,
Experience, Reach). Use them for atmosphere (glass, the 3D flag mark,
orange-as-signal), never as a source of truth for type, color tokens, or
rubric taxonomy. Canonical sources: `lib/design/tokens.css`, `DESIGN.md`,
`docs/design-rams-review.md`.
